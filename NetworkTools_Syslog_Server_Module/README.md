# NetworkTools Syslog Server bundle

Gói mã nguồn module hóa cho tính năng Syslog Server:

- UDP/TCP listener;
- Cisco/RFC-style parser;
- SQLite batch writer và query;
- connected-host panel chỉ lấy `t01_devices.success = 1`;
- menu `Syslog Server` / `Cancel Syslog Server`;
- cấu hình Cisco qua session registry hiện có;
- QML workspace, filter, log list, details và Settings;
- schema SQL và unit tests cơ bản.

Đọc `INTEGRATION_GUIDE.md` trước khi chép vào repository. Đây là bundle tích hợp, không phải bản thay thế hoàn chỉnh của thư mục `app`.
