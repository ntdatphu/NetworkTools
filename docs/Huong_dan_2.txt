1. Thiết lập Static Route cơ bản
Tác dụng: Tạo các đường định tuyến tĩnh trỏ về Next-hop.

Kiểm tra trên Router: Gõ lệnh show ip route static

JSON Test:

JSON
[
    {
        "target": { "ip": "192.168.121.106", "name": "vIOS6_EDGE" },
        "routing": { "type": "static", "mode": "setup" },
        "config": {
            "static_routes": [
                { "network": "10.9.9.0", "mask": "255.255.255.0", "next_hop": "10.0.69.9", "description": "TO_CORE_VLAN9" },
                { "network": "10.10.10.0", "mask": "255.255.255.0", "next_hop": "10.0.60.10", "description": "TO_CORE_VLAN10" }
            ]
        }
    }
]

2. Tinh chỉnh AD (Tạo Floating Static Route)
Tác dụng: Cài đặt AD = 210 để làm đường dự phòng (chỉ nổi lên bảng định tuyến khi đường chính đứt).

JSON Test:

JSON
[
    {
        "target": { "ip": "192.168.121.108", "name": "vIOS8_CORE" },
        "routing": { "type": "static", "mode": "setup" },
        "config": {
            "static_routes": [
                { "network": "0.0.0.0", "mask": "0.0.0.0", "next_hop": "10.0.58.5", "distance": 210 }
            ]
        }
    }
]

3. Gỡ bỏ Static Route
Tác dụng: Thêm cờ "action": "remove" để xóa các đường tĩnh đã cài.

JSON Test:

JSON
[
    {
        "target": { "ip": "192.168.121.108", "name": "vIOS8_CORE" },
        "routing": { "type": "static", "mode": "setup" },
        "config": {
            "static_routes": [
                { "network": "0.0.0.0", "mask": "0.0.0.0", "next_hop": "10.0.58.5", "description": "DEFAULT_TO_EDGE_V5", "action": "remove" }
            ]
        }
    }
]

 PHẦN 3: ĐỊNH TUYẾN ĐỘNG (OSPF)
1. Cài đặt OSPF (Kèm tính năng Stub Area & Passive)
Tác dụng: Thiết lập OSPF từ đầu, thiết lập các Area thường và Area Stub, mặc định khóa toàn bộ cổng (passive_interface_default: true) và đục lỗ mở các cổng được chỉ định.

Kiểm tra trên Router: Gõ lệnh show ip ospf neighbor và show ip route ospf

JSON Test:

JSON
[
    {
        "target": { "ip": "192.168.121.107", "name": "vIOS7_DIST_ABR1_STUB" },
        "routing": { "type": "ospf", "mode": "setup" },
        "config": {
            "process_id": 1, "router_id": "7.7.7.7",
            "passive_interface_default": true,
            "interfaces": [ { "name": "GigabitEthernet0/0" }, { "name": "GigabitEthernet0/1" } ],
            "networks": [ 
                { "ip": "10.0.0.0", "wildcard": "0.0.255.255", "area": 0 }, 
                { "ip": "7.7.7.7", "wildcard": "0.0.0.0", "area": 0 } 
            ],
            "areas": [
                { "id": 1, "type": "stub", "no_summary": true }
            ]
        }
    }
]
(Lưu ý: Để tắt toàn bộ tính năng khóa cổng, chỉ cần chuyển "passive_interface_default": false)

2. Tinh chỉnh ưu tiên DR/BDR (Priority)
Tác dụng: Can thiệp vào quá trình bầu chọn DR/BDR trên môi trường mạng Broadcast (Ethernet).

Kiểm tra trên Router: Gõ lệnh show ip ospf interface <tên_cổng>

JSON Test:

JSON
[
    {
        "target": { "ip": "192.168.121.108", "name": "vIOS8" },
        "routing": { "type": "ospf", "mode": "change" },
        "config": {
            "process_id": 1, "router_id": "8.8.8.8",
            "interfaces": [ 
                { "name": "GigabitEthernet0/0", "priority": 200 },
                { "name": "GigabitEthernet0/1", "priority": 0 }
            ]
        }
    }
]

3. Tinh chỉnh Hello/Dead Timers (Ép hội tụ nhanh)
Tác dụng: Đổi chu kỳ gửi Hello xuống 5s và Dead là 20s. (Bắt buộc phải cấu hình đồng bộ 2 đầu cáp mạng để không bị mất kết nối).

JSON Test:

JSON
[
    {
        "target": { "ip": "192.168.121.105", "name": "vIOS5_FAST_TIMER" },
        "routing": { "type": "ospf", "mode": "setup" },
        "config": {
            "process_id": 1, "router_id": "5.5.5.5",
            "interfaces": [
                { "name": "GigabitEthernet0/0", "hello_interval": 5, "dead_interval": 20 }
            ]
        }
    }
]

4. Tinh chỉnh AD (Administrative Distance)
Cách A: Đổi AD cho toàn bộ OSPF

JSON
[
    {
        "target": { "ip": "192.168.121.111", "name": "vIOS11_BRANCH1_AD" },
        "routing": { "type": "ospf", "mode": "setup" },
        "config": {
            "process_id": 1,
            "distance": { "type": "all", "value": 80 }
        }
    }
]
Cách B: Đổi AD theo 1 Router Nguồn (Source Router-ID) cụ thể

JSON
[
    {
        "target": { "ip": "192.168.121.108", "name": "vIOS8" },
        "routing": { "type": "ospf", "mode": "setup" },
        "config": {
            "process_id": 1, "router_id": "8.8.8.8",
            "distance": {
                "type": "source", "value": 90,
                "source_router_id": "7.7.7.7", "wildcard": "0.0.0.0"
            }
        }
    }
]
