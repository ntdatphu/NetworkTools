\chapter{Hướng dẫn cài đặt và chạy}
\label{app:install}

\section{Yêu cầu}

Máy cần Python 3.11 trở lên và \codeinline{uv}. Để dùng thiết bị thật, cần kết nối IP đến thiết bị và tài khoản quản trị phù hợp.

\section{Khởi tạo và chạy ứng dụng}

\begin{lstlisting}[language=bash,caption={Chạy NetworkTools từ repository}]
cd app
uv run python main.py
\end{lstlisting}

\codeinline{uv run} tự tạo hoặc cập nhật môi trường dự án và cài dependency khi cần; không bắt buộc chạy \codeinline{uv sync} trước. Lệnh \codeinline{uv run main.py} tương đương vì uv nhận diện trực tiếp Python script.

Nếu database runtime chưa có, chạy builder theo hướng dẫn trong \pathcode{docs/DATABASE_SCHEMA.md}. Không dùng các file schema cũ ở thư mục khác để thay thế tùy ý vì có thể tạo sai hợp đồng bảng.

\section{Chạy kiểm thử}

\begin{lstlisting}[language=bash,caption={Chạy toàn bộ test với cache trong workspace}]
cd app
$env:UV_CACHE_DIR = ".uv-cache"
uv run python -m unittest discover -s tests -v
\end{lstlisting}

\section{Biên dịch báo cáo}

\begin{lstlisting}[language=bash,caption={Biên dịch bằng XeLaTeX/latexmk}]

\end{lstlisting}
