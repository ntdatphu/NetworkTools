\chapter{Hướng dẫn cài đặt và chạy}
\label{app:install}

\section{Yêu cầu}

Máy cần Python 3.11 trở lên và \codeinline{uv}. Để dùng thiết bị thật, cần kết nối IP đến thiết bị và tài khoản quản trị phù hợp.

\section{Khởi tạo và chạy ứng dụng}

\begin{lstlisting}[language=bash,caption={Cài dependency và chạy NetworkTools}]
cd app
uv sync
uv run python main.py
\end{lstlisting}

Nếu database runtime chưa có, chạy builder theo hướng dẫn trong \pathcode{app/database/readme.md}. Không dùng các file schema cũ ở thư mục khác để thay thế tùy ý vì có thể tạo sai hợp đồng bảng.

\section{Chạy kiểm thử}

\begin{lstlisting}[language=bash,caption={Chạy toàn bộ test với cache trong workspace}]
cd app
$env:UV_CACHE_DIR = ".uv-cache"
uv run python -m unittest discover -s tests -v
\end{lstlisting}

\section{Biên dịch báo cáo}

\begin{lstlisting}[language=bash,caption={Biên dịch bằng XeLaTeX/latexmk}]
cd latex
./build.ps1
\end{lstlisting}
