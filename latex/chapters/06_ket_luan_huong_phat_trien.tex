\chapter{Kết luận và hướng phát triển}
\label{chap:ket-luan}

\section{Kết quả đạt được}

Đề tài đã xây dựng được nền tảng phần mềm hỗ trợ quản lý và cấu hình thiết bị mạng bằng Python.

\section{Hạn chế}

Phần mềm còn có thể bị giới hạn về số loại thiết bị hỗ trợ, khả năng bảo mật thông tin đăng nhập và phạm vi tự động hóa.

\section{Hướng phát triển}

\begin{itemize}
  \item Hỗ trợ nhiều hãng thiết bị hơn.
  \item Bổ sung phân quyền người dùng.
  \item Mã hóa thông tin đăng nhập.
  \item Tích hợp dashboard giám sát.
  \item Hỗ trợ API hoặc web dashboard.
\end{itemize}
